# 通用 Vue3 摄像头系统 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 项目简介
基于 Vue 3 + OpenTiny Vue 组件库构建的通用摄像头系统，提供完整的摄像头控制、媒体管理和参数调节功能，为后续改造为视频盘点系统奠定基础。

### 1.2 目标用户
- 需要摄像头功能的 Web 应用开发者
- 视频盘点系统的最终用户
- 需要实时监控和录制功能的企业用户

### 1.3 产品价值
- 提供开箱即用的摄像头功能组件
- 模块化设计，便于二次开发
- 支持与后端系统无缝对接
- 为视频盘点场景提供扩展能力

## 2. 核心功能

### 2.1 功能模块概览

| 模块 | 核心功能 |
|------|---------|
| 摄像头控制 | 设备枚举、开启/关闭、切换 |
| 实时预览 | 视频流展示、全屏切换 |
| 拍照截图 | 单帧捕获、图片下载 |
| 视频录制 | 音视频录制、录制控制 |
| 参数调节 | 亮度、对比度、饱和度等 |
| 云台控制 | 转动、缩放、预置位 |
| 媒体管理 | 图片/视频列表、预览、删除 |

### 2.2 功能详情

#### 2.2.1 摄像头控制模块
| 功能 | 说明 |
|------|------|
| 设备枚举 | 自动检测并列出所有可用摄像头设备 |
| 设备选择 | 支持切换不同摄像头 |
| 开启/关闭 | 控制摄像头的启动和停止 |
| 状态显示 | 实时显示摄像头连接状态 |

#### 2.2.2 实时预览模块
| 功能 | 说明 |
|------|------|
| 视频流展示 | 实时显示摄像头画面 |
| 分辨率选择 | 支持多种分辨率切换 |
| 全屏模式 | 支持全屏预览 |
| 画面对比 | 支持镜像、翻转等 |

#### 2.2.3 拍照截图模块
| 功能 | 说明 |
|------|------|
| 单帧捕获 | 一键截取当前画面 |
| 图片预览 | 截图后立即预览 |
| 图片下载 | 支持下载为 JPEG/PNG 格式 |
| 连拍模式 | 支持连续拍摄多张 |

#### 2.2.4 视频录制模块
| 功能 | 说明 |
|------|------|
| 开始录制 | 启动音视频录制 |
| 暂停/继续 | 支持录制暂停和恢复 |
| 停止录制 | 结束录制并保存 |
| 录制时长 | 实时显示录制时长 |
| 文件格式 | 支持 WebM/MP4 格式 |

#### 2.2.5 参数调节模块
| 功能 | 说明 |
|------|------|
| 亮度调节 | 0-100 范围调节 |
| 对比度调节 | 0-100 范围调节 |
| 饱和度调节 | 0-100 范围调节 |
| 色调调节 | 0-100 范围调节 |
| 曝光控制 | 自动/手动曝光 |
| 白平衡 | 自动/手动白平衡 |
| 参数保存 | 支持保存和加载预设 |

#### 2.2.6 云台控制模块
| 功能 | 说明 |
|------|------|
| 方向控制 | 上/下/左/右转动 |
| 缩放控制 | 光学/数字变焦 |
| 预置位 | 设置和调用预置位置 |
| 自动巡航 | 预设路径巡航 |

#### 2.2.7 媒体管理模块
| 功能 | 说明 |
|------|------|
| 文件列表 | 显示拍摄的图片和视频 |
| 缩略图预览 | 网格/列表视图切换 |
| 文件详情 | 查看文件信息（大小、时间等） |
| 文件操作 | 删除、重命名、下载 |
| 批量操作 | 支持批量删除和下载 |

## 3. 用户界面设计

### 3.1 设计风格
- **组件库**：OpenTiny Vue (Aurora 主题)
- **布局**：响应式三栏布局
- **配色**：企业级蓝色系
- **交互**：简洁直观，操作便捷

## 4. 扩展性规划 - 视频盘点系统

### 4.1 盘点功能规划
- **智能识别**：集成 AI 识别能力
- **盘点记录**：记录盘点过程和结果
- **数据导出**：支持 Excel/CSV 导出
- **报表生成**：自动生成盘点报告

### 4.2 后端对接规划
- 支持与企业 ERP/WMS 系统对接
- 提供标准化 REST API
- 支持 WebSocket 实时通信
